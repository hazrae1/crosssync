# Changelog

## 1.1.0

- Presentación de consola y documentación centradas en el flujo de configuración.
- Exportación del esquema `crosssync.profile/v1` con valores de origen.
- Reconocimiento de cuatro parámetros `viewmodel_*` propios de CS2.
- Lectura de nombres actuales de parámetros de mira y compatibilidad con CFG anteriores.
- Dos CFG de referencia con ajustes de mira, modelo del arma y compras.

## 1.0.0

- Versión inicial de CrossSync en C++17.
- Lectura de CFG con comentarios, comillas y comandos múltiples.
- Consola con etapas de migración, color y vista previa.
- Exportación de perfiles JSON.
- Paquetes para Windows y Linux con pruebas en GitHub Actions.
